# Elite Roofing

## Overview

Elite Roofing is a responsive roofing-company website designed to help homeowners understand available roofing services, build confidence in the company, and request a free estimate.

## Features

- Responsive navigation
- Professional hero section
- Roofing service cards
- Why Choose Us section
- Customer testimonials
- Free-estimate contact form
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## What I Learned

This project helped me strengthen my responsive web-development skills and understand how design choices support business goals. I learned how service cards improve readability, testimonials build trust, and calls to action guide visitors toward requesting an estimate.
