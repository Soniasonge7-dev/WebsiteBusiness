# BrightHome Cleaning

## Overview

BrightHome Cleaning is a responsive service-business website designed to help potential customers understand the company’s cleaning services, build trust, and request additional information.

## Features

- Responsive design
- Professional hero section
- Cleaning service cards
- Trust-building content
- Customer testimonials
- Contact section
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## What I Learned

This project strengthened my skills in organizing service information, creating reusable card layouts, using testimonials to build trust, and designing a clear customer journey.
